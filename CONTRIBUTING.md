# Contributing

Build and test using README.md. Describe the problem, user-visible behavior, and
validation in a pull request. Keep native libraries, matching headers, and their
licenses together. Dependency updates must pass the native compatibility suite.

Use generated test data and public research examples. Never commit real download
queues, credentials, access tokens, signing keys, or screenshots of personal data.
The bundled search provider is Academic Torrents; discuss a change in scope before
adding another provider. Generic torrent and magnet support remains supported.
