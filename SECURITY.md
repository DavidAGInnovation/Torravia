# Security reports

Please report vulnerabilities privately through the repository's GitHub security
advisory reporting feature when enabled. Avoid including credentials, personal
queues, or exploit details in public issues. If private reporting is unavailable,
open an issue requesting a private contact without disclosing the vulnerability.

Torravia's optional remote control requires an access token. Configure HTTPS or
use a trusted local network. Keep Xcode, macOS, and bundled dependencies updated.
